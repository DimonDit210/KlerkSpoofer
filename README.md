# Klerk Spoofer v1.0

**Klerk Spoofer** — программа для изменения аппаратных идентификаторов компьютера (HWID, MAC‑адрес, серийный номер диска, GUID, локальный IP и др.) в операционной системе Windows.

> **Исходный код программы не распространяется.** Данный репозиторий содержит только документацию и файлы, необходимые для использования уже собранного приложения.

---

## Принцип работы

Klerk Spoofer модифицирует ключевые идентификаторы оборудования, которые считываются античит‑системами и программами для привязки лицензий. После успешного спуфинга ваш компьютер воспринимается как новое устройство, что позволяет:

- обойти HWID‑бан в онлайн‑играх;
- сбросить привязку лицензий к «железу»;
- защитить конфиденциальность аппаратных данных.

Все изменения обратимы: перед каждой операцией автоматически создаётся резервная копия изменяемых разделов реестра (папка `backups`).

## Как пользоваться

1. **Скачайте** актуальную версию `KlerkSpoofer.exe` из раздела [Releases](https://github.com/).
2. **Запустите программу от имени администратора** (ПКМ → «Запуск от имени администратора»).
3. При первом запуске будут созданы резервные копии реестра и показан файл `Readme.txt`.
4. **Активируйте лицензионный ключ** (приобретается отдельно у официального продавца).
5. Выберите нужную операцию в меню:
   - **Спуфинг** — изменение идентификаторов (HWID, MAC, диск, GUID, IP и др.);
   - **Очистка кэша** — удаление следов Ubisoft / Valorant;
   - **Тест функций** — диагностика доступности спуф‑методов;
   - **Бэкапы** — просмотр и восстановление резервных копий реестра.
6. После выполнения спуф‑операций **перезагрузите компьютер**.
